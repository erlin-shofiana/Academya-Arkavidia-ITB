# **Exploration of Bank Direct Marketing Dataset : Predicting Subscription to Term Deposit**

## 📌 Project Overview
This project focuses on building a classification model to predict the success of a direct marketing campaign for term deposit subscriptions. Using the Bank Direct Marketing dataset, we analyze customer characteristics, campaign-related factors, and previous interaction history to identify patterns influencing subscription outcomes.

In addition to predictive modeling, we developed an interactive dashboard to visualize campaign performance, customer segmentation, and key insights to support data-driven decision-making.
